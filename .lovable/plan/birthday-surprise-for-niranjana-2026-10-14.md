# Birthday Surprise for Niranjana

Build the supplied birthday brief as the live `/` experience, using the existing TanStack app rather than delivering a separate HTML/CSS/JS bundle.

## Experience
- Create a cinematic midnight-star entry with a clear “Open Your Surprise” transition into a celebratory birthday scene.
- Include an animated cake and wish interaction, six editable photo placeholders with a working lightbox, interactive affection cards, an animated personal letter, a graceful optional music control, and a final celebration with replay.
- Use accessible semantic controls, responsive layouts, reduced-motion support, and graceful missing-media handling.

## Visual direction
- Use a rich midnight-universe aesthetic with animated stars, violet nebula light, rose-pink hearts, and restrained gold accents; preserve dark, minimal typography and project design tokens.
- Generate one bespoke cosmic image to enrich the birthday scenes; keep particles and scene transitions lightweight and CSS-driven.

## Technical details
- Implement in the existing TanStack Start route and global design system, with all interactive state in the page and styling in `src/styles.css`.
- Add unique route metadata, project memory for the chosen experience style, and the required root architecture note.
- Verify preview build status and exercise the complete main interaction flow at desktop and mobile sizes.
